# 云端与更新

本文档介绍托盘菜单中与云端连接和自动更新相关的菜单项。

## 连接云端

| 属性 | 值 |
|------|-----|
| 类型 | 复选框 |
| 默认值 | 关闭 |

控制客户端从云端服务端获取配置还是使用本地配置。勾选后客户端将通过 API 从服务端拉取课表、作息、天气等数据；未勾选时使用本地 `scheduleConfig.js` 中的默认配置。

## 更新源（可选）

| 属性 | 值 |
|------|-----|
| 类型 | 输入框 |
| 默认值 | 空（使用默认 GitHub Releases 镜像） |

设置自定义自动更新镜像源地址，需指向包含 `latest.yml` 的目录。修改后需重启应用生效。

## 检查更新

| 属性 | 值 |
|------|-----|
| 类型 | 按钮 |

立即手动检查是否有新版本可用。仅在打包版本（`app.isPackaged`）中生效，开发模式下会提示"开发模式下不检查更新"。

## 自动更新

| 属性 | 值 |
|------|-----|
| 类型 | 复选框 |
| 默认值 | 开启 |

是否启用自动更新检测。开启后，应用启动 3 秒后自动检查更新。

## 云端服务

| 属性 | 值 |
|------|-----|
| 类型 | 输入框 |
| 默认值 | `class.getastra.cn` |

设置后端 API 服务器地址。修改后不会立即重新拉取配置，需重新获取课表（托盘「更新课表」）或重启客户端后生效。

## 安全连接

| 属性 | 值 |
|------|-----|
| 类型 | 复选框 |
| 默认值 | 开启 |

是否使用 HTTPS/WSS 加密连接。关闭后使用 HTTP/WS。

## 所在班级

| 属性 | 值 |
|------|-----|
| 类型 | 输入框 |
| 默认值 | `39/2023/1` |

设置班级标识，格式为 `学校/年级/班级`（如 `39/2023/1`）。修改后触发 WebSocket 重连。

## 刷新天气

| 属性 | 值 |
|------|-----|
| 类型 | 按钮 |

立即手动刷新天气数据。
