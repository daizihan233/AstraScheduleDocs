# 自动更新

客户端使用 electron-updater 实现自动更新。更新机制的工作流程如下：

## 更新流程

1. **启动检查**：应用启动 3 秒后自动检查更新。
2. **更新源**：默认从 GitHub Releases 获取更新（通过镜像代理加速）。可通过托盘菜单"更新源（可选）"修改为自定义地址。
3. **静默下载**：检测到更新后自动在后台下载，托盘提示显示下载进度百分比。
4. **自动安装**：下载完成后提示“更新可用”，自动退出并安装新版本，安装完成后重新启动。**这个过程没有确认提示** 。
5. **手动检查**：通过托盘菜单“检查更新”随时手动触发检查。

## 限制条件

- 自动更新仅在打包版本中生效。开发调试版本不会触发更新检测。
- 版本号必须符合语义化版本格式，否则自动更新会被禁用。
- 如果网络环境无法访问 GitHub，可通过“更新源（可选）”菜单项配置内部镜像地址。
- Windows 7 系统可能需要安装特定系统补丁才能正常执行自动更新。（不过通常情况下你应该已经装过了）

## 版本号格式

客户端使用自定义滚动版本号 `YYYYMM.D.N`（年月.日.运行序号），而非标准的语义化版本定义。electron-updater 通过 `isSemver()` 检查适配。

示例：`202510.2.40` 表示 2025年10月02日，第40次构建。

## 更新源配置

默认更新源（GitHub Releases 镜像代理，由开发者自行维护）：

```
https://hubproxy.khbit.cn/https://github.com/AstraSchedule/desktop/releases/latest/download
```

客户端默认通过 `hubproxy.khbit.cn` 镜像加速访问。

可通过托盘菜单「更新源（可选）」修改为自定义地址，需指向包含 `latest.yml` 的目录。
