# 横幅通知

横幅通知位于客户端窗口顶部，以跑马灯滚动的方式展示自定义文字或天气预警信息。

## 跑马灯滚动效果

横幅采用自定义 JavaScript 实现的跑马灯滚动动画。核心参数和机制如下：

### 滚动速度

文字滚动速度为每秒 80 像素。

### 双段无缝循环

横幅采用双段文本加间隔的设计实现无缝循环滚动：

1. 第一段文字（seg1）从右侧进入，向左滚动。
2. 第一段文字末尾添加四个不间断空格作为间隔。
3. 第二段文字（seg2）紧接间隔后开始滚动。

当第一段文字完全滚出左侧视野时，滚动偏移重置，实现首尾衔接的无缝循环效果。

### 短文字居中

当横幅文字总宽度小于容器宽度（无需滚动即可完整显示）时，自动切换为居中静态显示模式。

### 内容变化响应

当横幅文字被更新时，滚动动画自动重启以适配新的文字长度。这支持天气预警与普通横幅之间的动态切换。

## 横幅隐藏

当横幅文字为空字符串时，横幅自动隐藏。

## 天气预警替代横幅

参考：[极端天气预警联动横幅](./weather.md#极端天气预警联动横幅)

横幅支持被极端天气预警内容替代，此功能由管理端的两个开关联合控制：

- **存在预警时替代横幅文本**：是否启用天气预警替代。当此开关开启时，客户端优先使用天气预警文字作为横幅内容；当预警数据不存在或此开关关闭时，回退为普通的 `banner_text`。
- **是否使用简略的预警信息**：预警显示模式。开启时使用简略预警标题，关闭时使用详细预警描述。

预警替代行为在客户端收到新的天气数据（包括预警信息）时触发，将自动调用重新渲染横幅内容。

## 管理端配置

横幅相关配置集中在管理端"通用设置"页面：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `banner_text` | 普通横幅文字内容，支持任意文本 | 空字符串 |
| `weather_alert_override` | 是否启用天气预警替代横幅 | `false` |
| `weather_alert_brief` | 预警是否使用简略模式 | `false` |

修改配置后，客户端在数秒内（WebSocket 模式）或下一个轮询周期（Serverless 模式）更新横幅显示。WebSocket 断开时，客户端保持最后的配置状态。
