# 课表配置

路径：`/config/:school/:grade/:cls/schedule`

配置指定班级每周七天的课程安排。页面进入后自动加载该班级的现有课表、可用科目列表、可用作息表列表。

## 顶部信息栏

显示当前操作的学校、年级、班级，确认操作目标无误。

## 配置表单

课表配置卡片内是一张「星期 × 节次」表格：

- 表头第一行为星期（周日到周六）
- 表头第二行为**作息表选择行**：为每一天选择当天使用的作息表模板（如"常日""周五"等），切换后该天的课程行数会自动更新
- 表格主体为节次行：行数由该天所选作息表包含的节数决定（后端按作息表中配置的最大课时序号推算，例如配置了第 1 至第 7 节，则显示 7 行），每格为对应星期该节课的科目选择器

每个科目格子的配置方式：

- 默认单选一个科目，选项来源于该年级的科目管理配置（显示缩写，如"语""数""英"）
- 支持**多周轮换**：点击格子旁"单周/多周"切换按钮后，该格变为多周轮换输入，用 `/` 分隔各周课程（如 `物/化/地/数` 表示四周分别上物理、化学、地理、数学），对应[每周轮换课程](../../features/schedule)功能

## 提交

点击"提交"按钮后弹出密码确认弹窗，输入正确密码后通过 JWT + 密码确认将 JSON 数据 PUT 到后端。提交成功提示"服务端说行"。

## 提交前预览

页面底部 JSON 预览区域实时展示即将提交的完整数据结构，包含 `daily_class` 数组，每个元素包含 `Chinese`、`English`、`classList`（课程数组）、`timetable`（作息表名称）。
