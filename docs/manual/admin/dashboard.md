# 仪表盘

仪表盘是进入管理后台后的默认首页，提供系统实时运行状态概览。

## Serverless 模式

由于 Serverless 本身的特性，服务是无状态的，所以没有下面这些数据。取而代之的是 Logo 和一言。

## 今日统计

顶部卡片展示三项核心指标：

- **天气上游 API 响应错误**：当日调用和风天气 API 返回错误的总次数。数值偏高说明天气服务可能出现异常或 API 配额不足。
- **WebSocket 异常断连**：当日所有客户端 WebSocket 异常断开的总次数。
- **正在连接的客户端数量**：当前保持 WebSocket 连接的客户端总数。

## 各班详情

下方表格展示每个班级的实时连接状态：

| 列 | 说明 |
|----|------|
| 班级 | 班级名称，由学校/年级/班级路径拼接 |
| 连接状态 | `保持连接`（绿色标签）或 `已断开连接`（红色标签） |
| 今日异常断连次数 | 该班级当日累计断连次数 |

表格支持按班级名称、连接状态、异常断连次数排序。
