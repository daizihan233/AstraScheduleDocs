# 结构管理

路径：`/structure`

管理学校 → 年级 → 班级的三级组织结构。课表、作息、科目、设置等所有配置都挂在具体的班级上，因此需要先建好结构才能开始配置。

## 结构树

页面以树形结构展示所有学校，每个学校下列出年级，年级下列出班级。每个节点旁有对应的操作按钮：

- **学校**：新增年级、删除学校
- **年级**：新增班级、删除年级
- **班级**：删除班级

## 新增学校 / 年级 / 班级

1. 点击「新增学校」输入学校名称
2. 创建学校后引导继续「新增年级」输入年级名称（建议使用入学年份，如 `2023`）
3. 创建年级后引导继续「新增班级」输入班级名称（如 `1`、`2`…）

> 班级标识格式为 `学校/年级/班级`（如 `39/2023/1`），会直接用于客户端「所在班级」的填写，建议使用简短易输入的编号而非中文长名称。

## 删除

删除学校/年级/班级需要输入当前管理员密码确认。

> ⚠️ 删除学校会连同其下所有年级、班级及配置数据一并删除，请谨慎操作。建议删除前先[导出备份](../features/backup)。
