# 用户管理

路径：`/users`

管理本租户（或部署）内的登录账号。**仅 `admin` 角色可进入此页面**。

## 用户列表

表格展示所有用户，包含：

| 列 | 说明 |
|----|------|
| 用户名 | 登录账号 |
| 角色 | 权限标签：管理员 / 校写入 / 级写入 / 班写入 / 只读 |
| 作用域 | 该用户可操作的学校/年级/班级范围 |
| 操作 | 修改、删除 |

## 创建用户

点击「新增用户」，填写：

- **用户名**：登录账号
- **密码**：初始密码
- **角色**：
  - `admin`（管理员）：全局管理，不受作用域限制
  - `school_w`（校写入）：可写指定学校下的所有数据
  - `grade_w`（级写入）：可写指定年级下的所有数据
  - `class_w`（班写入）：可写指定班级的数据
  - `readonly`（只读）：仅可查看，不可写
- **作用域**：按角色自动过滤的学校/年级/班级树形选择器。选择 `admin` 或 `readonly` 时无需选择作用域
- **必须修改密码**：开启后该用户首次登录会被要求修改密码
- **必须修改用户名**：开启后该用户首次登录会被要求修改用户名

## 修改 / 删除

- 修改用户：可调整角色、作用域、重置密码等
- 删除用户：点击删除并输入当前管理员密码确认后生效

> 写操作（创建/修改/删除）都需要输入当前登录管理员的密码进行二次确认。
