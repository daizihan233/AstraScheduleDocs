# Scope（生效域 / 作用域）

## 通俗解释

生效域就是"这条配置管哪些班级"。可以管全校、管某个年级，也可以只管某个班。设置好生效域，一条规则就能批量生效，不用逐班设置。

## 专业解释

Scope（作用域）是数据或权限的适用范围标识，在本项目中采用 `学校/年级/班级` 三级层次：

- **学校级**（如 `39`）：覆盖全校所有班级
- **年级级**（如 `39/2023`）：覆盖该年级所有班级
- **班级级**（如 `39/2023/1`）：仅覆盖单个班级

## 在 AstraSchedule 中

- 自动任务（调休、作息调整、课表调整）、倒数日配置通过 `scope` 决定作用于哪些班级
- 用户账号通过 `scope` + 角色（`school_w`/`grade_w`/`class_w`）限定可读写的数据范围
- 管理端创建任务时以多选下拉选择生效域，选中上级后下级自动禁用（由上级覆盖）
